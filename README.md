# Focus4Dex

Focus4Dex: Action-Guided Visual Information Selection and Utilization for Dexterous Manipulation

[Project website](https://0309hws.github.io/Focus4Dex.github.io/)

This repository hosts the project website and its existing paper, figures, and demonstration videos.

## Deployment

GitHub Pages publishes the `main` branch from the repository root. `.nojekyll` enables direct static-file hosting; no build step or external dependency is required.
